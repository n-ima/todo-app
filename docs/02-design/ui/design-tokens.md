# デザイントークン

モックアップ（このフォルダの HTML）と実装の `wwwroot/css/app.css` は、この表の CSS 変数だけを使う。社内ツールのため装飾は控えめにし、「期限の強調が一目で分かる」ことを最優先にする（US-013・P1）。

## 色

| 変数 | 値 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 画面の背景 |
| `--surface` | `#f6f7f9` | ヘッダー・絞り込みバー・カード |
| `--border` | `#d0d5dd` | 罫線（装飾。情報を載せない） |
| `--text` | `#1f2937` | 本文 |
| `--text-muted` | `#4b5563` | 補足（作成日時・注記） |
| `--text-dim` | `#6b7280` | 薄く表示する行（完了の親・絞り込みの祖先）。`opacity` は使わない（コントラストが測れなくなるため） |
| `--primary` | `#1d4ed8` | リンク・主ボタンの背景（文字は白） |
| `--selected` | `#eef4ff` | 行のホバー・選択 |
| `--danger` | `#b42318` | 期限超過の文字・危険な操作ボタンの背景 |
| `--danger-bar` | `#d92d20` | 期限超過の行の左端の帯（4px） |
| `--danger-bg` | `#fef3f2` | 期限超過の行の背景 |
| `--warn` | `#8a4b00` | 期限間近の文字 |
| `--warn-mark` | `#b45309` | 期限間近の印（アイコン・帯） |
| `--warn-bg` | `#fffaeb` | 期限間近の背景・警告帯 |
| `--badge-bg` | `#e8ecf2` | 状態バッジ（未完了） |
| `--badge-done-bg` | `#eef0f3` | 状態バッジ（完了扱い。文字 `#344054`） |

### コントラスト比の実測（WCAG 2.x の相対輝度式。2026-09-26 に python で計算）

| 組み合わせ | 比 | 基準 |
|---|---|---|
| `--text` / `--bg` | 14.68 | 4.5 以上 ✓ |
| `--text-muted` / `--bg` | 7.56 | ✓ |
| `--text-dim` / `--bg` | 4.83 | ✓ |
| `--text-dim` / `--surface` | 4.51 | ✓（ぎりぎり。`--surface` 上の薄い行は太字にしない） |
| `--primary` / `--bg`（リンク） | 6.70 | ✓ |
| 白 / `--primary`（主ボタン） | 6.70 | ✓ |
| `--danger` / `--bg` | 6.57 | ✓ |
| `--danger` / `--danger-bg` | 6.05 | ✓ |
| 白 / `--danger`（削除ボタン） | 6.57 | ✓ |
| `--warn` / `--bg` | 6.80 | ✓ |
| `--warn` / `--warn-bg` | 6.52 | ✓ |
| `--text` / `--badge-bg` | 12.38 | ✓ |
| `#344054` / `--badge-done-bg` | 9.16 | ✓ |
| `--danger-bar` / `--bg`（非テキスト） | 4.83 | 3.0 以上 ✓ |
| `--warn-mark` / `--bg`（非テキスト） | 5.02 | 3.0 以上 ✓（当初案 `#dc8b00` は 2.71 で不合格のため変更） |
| `--warn-mark` / `--warn-bg` | 4.81 | 3.0 以上 ✓ |

- 期限超過・期限間近は色だけで区別しない。必ずアイコン（超過「!」・間近「◷」）と文字（「期限超過」「期限間近」）を併記する（NFR-014）。赤と黄は色覚の違いで区別しにくい場合があるが、文字で区別できる。
- 状態（未着手・進行中・完了…）は管理者が増やせるため、状態ごとの色分けはしない（識別は文字で行う）。

## 文字

| 変数 | 値 |
|---|---|
| `--font` | `"Segoe UI", "Yu Gothic UI", "Meiryo", system-ui, sans-serif`（OS 同梱のみ。Web フォントは読み込まない＝外部送信なし） |
| `--font-mono` | `Consolas, "BIZ UDGothic", monospace`（メモの編集欄・コード） |
| `--fs-base` | 14px（本文・表） |
| `--fs-small` | 12px（注記・エラー ID） |
| `--fs-h1` | 20px（画面タイトル・タスク名） |
| 行の高さ | 1.6（本文）・表の行は 36px |

## 余白・形

| 変数 | 値 |
|---|---|
| `--sp-1` / `--sp-2` / `--sp-3` / `--sp-4` | 4px / 8px / 12px / 16px |
| `--sp-6` | 24px |
| `--radius` | 4px（ボタン・入力・バッジ） |
| `--indent` | 20px（ツリーの 1 段の字下げ。768px 未満は 12px） |
| `--focus` | `2px solid #1d4ed8`（`outline-offset: 2px`） |
