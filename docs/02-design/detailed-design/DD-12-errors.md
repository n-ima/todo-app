# DD-12 エラー ID 一覧

表示の形は DD-01 §5。`{}` は差し込み値。画面では文言の後ろに `（E-XXX）` を小さく併記する。

## 認証・利用者

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-AUTH-FAILED | 200（画面再表示） | ログイン ID またはパスワードが正しくありません | DD-03 §2（ID 不存在・パスワード誤り・無効化） |
| E-AUTH-LOCKED | 200（画面再表示） | ログインに続けて失敗したため、15 分間ログインできません。時間をおいてからもう一度お試しください | DD-03 §2 |
| E-AUTH-REQUIRED | 401 | ログインしてください（画面はログインへ転送） | DD-03 §1 |
| E-AUTH-MUST-CHANGE | 403 | 初期パスワードを変更してください | DD-03 §3 |
| E-PWD-CURRENT | 200 | 現在のパスワードが正しくありません | DD-03 §3 |
| E-PWD-LENGTH | 200 | パスワードは 8 文字以上 128 文字以下にしてください | DD-03 §3・§4 |
| E-PWD-CONFIRM | 200 | 確認用のパスワードが一致しません | DD-03 §3 |
| E-PWD-SAME | 200 | 現在（初期）のパスワードとは別のパスワードにしてください | DD-03 §3 |
| E-USER-DUPLICATE | 200 | このログイン ID は既に使われています | DD-03 §4 |
| E-USER-LOGINID-FORMAT | 200 | ログイン ID は半角英数字と . _ - の 50 文字以内で入力してください | DD-03 §4 |
| E-USER-LAST-ADMIN | 200 | 管理者が 1 人もいなくなります | DD-03 §4 |

## 権限

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-PERM-DENIED | 403 | このタスクを編集できるのは担当者と管理者だけです | DD-04 §1（FR-001） |
| E-PERM-SUBTREE | 403 | 配下に、あなたが編集できないタスクがあるため操作できません: {タイトル一覧} | DD-04 §5・§7（A-013） |
| E-PERM-ADMIN-ONLY | 403 | この操作は管理者だけが行えます | DD-03 §4・DD-05 §6 |

## タスク

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-TASK-NOT-FOUND | 404 | タスクが見つかりません（削除された可能性があります） | 各操作 |
| E-TASK-TITLE-REQUIRED | 400 | タイトルは必須です | DD-04 §2 |
| E-TASK-TITLE-LENGTH | 400 | タイトルは 200 文字以内にしてください | DD-04 §2 |
| E-TASK-DATE-ORDER | 400 | 期限は開始日以降にしてください | DD-04 §2（FR-002） |
| E-TASK-ASSIGNEE-INACTIVE | 400 | 無効化された利用者は担当者に設定できません | DD-04 §2 |
| E-TASK-CHILDREN-OPEN | 409 | 未完了の子タスクが {n} 件あります。完了にしますか | DD-04 §4（確認ダイアログの契機） |
| E-TASK-CYCLE | 400 | 自分自身や配下のタスクの下には移動できません | DD-04 §5 |
| E-TASK-PARENT-GONE | 409 | 移動先（親）が見つかりません。画面を読み込み直してください | DD-04 §3・§5 |
| E-MEMO-TOO-LONG | 400 | メモは 100,000 文字以内にしてください（現在 {n} 文字） | DD-07 §4（FR-005） |
| E-VALIDATION | 400 | 入力内容を確認してください: {項目} | 形式違反全般 |
| E-PROJECT-NAME | 400 | プロジェクト名は 1〜100 文字で入力してください | DD-04 §8 |

## ロック

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-LOCK-HELD | 409 | {保持者}さんが編集中です（{HH:MM} から） | DD-05 §3 |
| E-LOCK-HELD-SUBTREE | 409 | {保持者}さんが編集中のタスク『{タイトル}』が含まれるため操作できません | DD-04 §5・§7・§8 |
| E-LOCK-LOST | 409 | ロックが解除されています。入力内容は下書きとして残しました。もう一度「編集する」を押してください | DD-05 §3 |

## ゴミ箱・通知・ワークフロー

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-TRASH-NOT-FOUND | 404 | このタスクはゴミ箱にありません（完全に削除された可能性があります） | DD-04 §7 |
| E-TRASH-PARENT-MISSING | 409 | 元の親が存在しません。先に親を戻すか、管理者に相談してください | DD-04 §7 |
| E-NOTIFY-TASK-DELETED | 200（一覧に表示） | このタスクは削除されています | DD-08 §2 |
| E-WF-NAME-DUPLICATE | 400 | 同じ名前の状態が既にあります | DD-08 §1 |
| E-WF-IN-USE | 409 | この状態のタスクが {n} 件あります（ゴミ箱を含む） | DD-08 §1 |
| E-WF-NEED-DONE | 409 | 完了扱いの状態が 1 つ以上必要です | DD-08 §1 |
| E-WF-LAST-STATUS | 409 | 状態を 1 つ以上残してください | DD-08 §1 |

## システム・バックアップ

| ID | HTTP | 文言 | 発生箇所 |
|---|---|---|---|
| E-CSRF | 400 | 画面の有効期限が切れました。画面を読み込み直してから、もう一度操作してください | DD-01 §6（Antiforgery の検証失敗。フォームはエラー画面、API は JSON） |
| E-DB-BUSY | 503 | 混み合っています。少し待ってからもう一度操作してください | DD-01 §4 |
| E-SYS-UNEXPECTED | 500 | 予期しないエラーが発生しました。管理者にお知らせください（相関 ID: {id}） | DD-01 §5 |
| E-SYS-SCHEMA-MISMATCH | ―（起動失敗） | データベースの版（{db}）がアプリの版（{app}）と一致しません。更新スクリプトを使ってください | DD-02 §1（イベントログ） |
| E-BACKUP-SNAPSHOT | ―（管理画面） | データベースのコピーに失敗しました | DD-09 §3 |
| E-BACKUP-SECRET | ―（管理画面） | バックアップ鍵を読み込めません | DD-09 §3 |
| E-BACKUP-SHARE | ―（管理画面） | 共有フォルダに接続または書き込みできません | DD-09 §3 |
| E-RESTORE-DECRYPT | ―（CLI 30） | 復号できません（鍵が違うか、ファイルが壊れています） | DD-09 §4・DD-10 §4 |
| E-RESTORE-INTEGRITY | ―（CLI 31） | バックアップの内容が壊れています | DD-10 §4 |
| E-RESTORE-NEWER-SCHEMA | ―（CLI 32） | このバックアップは新しい版で作られています | DD-10 §4 |
| E-CLI-SERVICE-RUNNING | ―（CLI 40） | サービス TodoApp が動いています。停止してから実行してください | DD-10 §1 |

エラー ID は `ErrorIds` クラスの定数と 1 対 1。テストは ID で判定する（文言の変更でテストが壊れないように）。
