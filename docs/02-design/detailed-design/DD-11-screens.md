# DD-11 画面

見た目の正は [ui/](../ui/) のモックアップと [design-tokens.md](../ui/design-tokens.md)。ここは構成・動線・振る舞いを定める。

## 1. 共通レイアウト（`_Layout.cshtml`）

- ヘッダー: アプリ名「TODO アプリ」／ナビ「一覧」「カレンダー」「ゴミ箱」（一覧・カレンダーを表示中は、ナビの「一覧」「カレンダー」も現在の絞り込みクエリを引き継ぐ。US-012）／（管理者）「管理」／通知ベルと未読件数（DD-08 §2）／表示名とメニュー（パスワード変更・ログアウト）。
- 管理者向けのバックアップ警告帯（DD-09 §6）はヘッダー直下。
- フラッシュメッセージ（操作の結果）はヘッダー直下に表示し、`role="status"`。
- `<meta name="csrf-token">` と `<meta name="autosave-seconds">` を出す（JS 用）。インラインスクリプトは書かない（CSP）。

## 3. タスク詳細の操作の出し分け（FR-001・US-010・US-011）

| 状況 | 編集する | 移動・削除 | 強制解除 |
|---|---|---|---|
| 編集権限なし | 無効＋注記「このタスクを編集できるのは担当者と管理者だけです」 | 無効（同じ注記） | 出さない（一般）/ 出す（管理者） |
| 権限あり・未ロック | 有効 | 有効（実行時にサーバーが配下を検査） | ― |
| 他人がロック中 | 無効＋帯「◯◯さんが編集中（HH:MM から）」 | 有効（実行時に `E-LOCK-HELD-SUBTREE`） | 管理者だけ |
| 本人がロック中（別タブ等） | 「編集を再開する」 | 有効 | ― |

- 移動: ダイアログにプロジェクトとタスクのツリー（自分と子孫は選べない表示）を出し、選んで「ここへ移動」。エラーはダイアログ内に表示（編集できないタスクの一覧、ロック中の利用者名）。
- 削除: 確認ダイアログ「『タイトル』と子タスク n 件をゴミ箱へ移します。30 日以内なら元に戻せます」。
- 保存時の完了警告: `E-TASK-CHILDREN-OPEN` を受けたら「未完了の子タスクが n 件あります。完了にしますか」の確認ダイアログ（「完了にする」「戻る」）。
- ダイアログは `<dialog>` 要素で作り、Esc で閉じ、開いたときに最初の操作要素へフォーカス。

## 4. レスポンシブ（NFR-011）

- 幅 768px 以上: 一覧は表形式。詳細は左に項目、右にメモ（1200px 以上で編集中は編集欄とプレビューの 2 分割）。
- 幅 768px 未満（スマートフォン）: **閲覧専用レイアウト**。一覧は 1 列のカード（タイトル・状態・担当者・期限）で字下げを小さく、操作ボタン（編集する・移動・削除・上へ/下へ・＋子タスク・＋プロジェクト・CSV）を出さない。詳細は項目→メモ→変更履歴の縦並び。カレンダーは週表示を既定にする。
- 閲覧専用はレイアウト上の扱いで、サーバーの認可は変えない（PC と同じ権限）。

## 5. アクセシビリティ（NFR-014）

- すべての入力に `<label for>`。必須項目は「（必須）」の文字を付ける（色だけにしない）。
- 色のコントラスト 4.5:1 以上（design-tokens.md で実測値を記録）。期限超過・期限間近・完了（薄い表示）は色＋アイコン＋文字。
- ツリーの行は `<table>` と `aria-level`・`aria-expanded`（展開ボタンは `<button>`）。キーボードで展開・遷移できる。
- エラーはフィールドに `aria-describedby` で結び、ページ上部の要約に `role="alert"`。

## 6. 文言の統一

用語は glossary.md に従う（「タスク」「プロジェクト」「担当者」「期限」「状態」「完了扱い」「ロック」「下書き」「ゴミ箱」）。日付は `YYYY/MM/DD`、日時は `YYYY/MM/DD HH:mm`（NFR-015）。
